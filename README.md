# Bright Hearts Assets

Pixel art assets for the **Bright Hearts** project / game.

## Structure

### Deployables / Units
- `deploy_01_sentry_turret` — Sentry Turret (mechanical defense unit)
- `deploy_02_mechanical_snare` — Mechanical Snare (trap)
- `deploy_03_oil_trap` — Oil Trap
- `deploy_04_scout_drone` — Scout Drone
- `deploy_05_iron_fortress_barricade` — Iron Fortress Barricade (defensive structure)
- `deploy_06_warlord_battle_banner` — Warlord Battle Banner (with character holding a flaming banner)

### Heroes
- `hero_04_gunman` — Gunman hero
- `hero_05_engineer` — Engineer hero

## File Variants
For most deployables there are three versions:
- `*_64x64.png` — Small icon / thumbnail (64×64)
- `*_cutout.png` — Transparent cutout version (larger, clean edges)
- `*_raw.png` — Raw / full version

## Notes
These are classic pixel-art style sprites with a warm, metallic / fantasy-tech palette (coppers, browns, glowing orange accents).

The repository currently contains only the README. Binary image assets are provided separately (see conversation or the downloadable zip).
